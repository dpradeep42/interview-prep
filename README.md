# Pradeep — Interview Q&A Bank

A static, self-contained study site: 650 interview questions in nine parts built from my resume and my own question list (.NET backend, IQVIA IRT, AWS, messaging, MCP and AI tooling), with difficulty tags, memory hooks, 133 diagrams and tables, and 44 stories with follow-up questions. The "Your list" tab shows all 982 questions from my list in the file's order, each with the answer that covers it.

- `index.html` is the site, also served by GitHub Pages if enabled.
- `interview-prep.html` is the same site as one file you can open directly in a browser. Diagrams load Mermaid from the jsDelivr CDN.
- `build/` holds the source data and the scripts that generate the HTML (`node build/build.mjs`).

Features: a Your list tab, nine parts plus an All view, search, topic and difficulty filters, "Only with pictures", "Only with stories", and Expand/Collapse all. Light and dark mode follow the device setting.

Numbers in [square brackets] are suggested story details to adjust; unbracketed figures come from the resume.
