# Pradeep — Interview Q&A Bank

A static, self-contained study site: 221 interview questions built from my resume (.NET backend, IQVIA IRT, AWS, messaging, MCP and AI tooling), with difficulty tags, memory hooks, 73 diagrams and tables, and 40 STAR stories with follow-up questions.

- `index.html` is the site, also served by GitHub Pages if enabled.
- `interview-prep.html` is the same site as one file you can open directly in a browser. Diagrams load Mermaid from the jsDelivr CDN.
- `build/` holds the source data and the scripts that generate the HTML (`node build/build.mjs`).

Features: three parts plus an All view, search, topic and difficulty filters, "Only with pictures", "Only with stories", and Expand/Collapse all. Light and dark mode follow the device setting.

Numbers in [square brackets] are suggested story details to adjust; unbracketed figures come from the resume.
