- The model picks a tool from the user's intent and descriptions; the host may ask the user to confirm before tools/call runs.

+@p8-6

+@p8-7

- Each user's own PAT means Azure DevOps permissions still apply; the server can't do more than the user could.
+@p8-8

+@p8-9

- Authorization is enforced by Azure DevOps permissions plus tool-level rules in the server.
+@p8-10

- Azure DevOps history remains the system of record for builds, releases and approvals.
