@p4-25
Q: override replaces a virtual method so base-typed references call the derived version; new hides the base method (method hiding), so which runs depends on the declared reference type, a common source of bugs.

```csharp
class Base { public virtual string A() => "base"; public string B() => "base"; }
class Derived : Base { public override string A() => "derived"; public new string B() => "derived"; }

```

? What does the CS0108 warning mean? :: You're hiding an inherited member without saying new.

Q: The stack is per-thread LIFO memory for method frames, locals and value types, very fast and freed when the method returns; the heap is shared managed memory for objects (reference types), cleaned by the GC. ? Are structs always on the stack? :: No; fields of a class, array elements, boxed values and captured variables live on the heap.
? What is the LOH? :: The Large Object Heap for objects of 85 KB or more, collected with Gen 2.
