@p7-1
Q: React is a JavaScript library for building user interfaces from reusable components. You describe what the UI should look like for a given state, and React reconciles changes efficiently (virtual DOM diffing) to update only what changed in the real DOM.
- React 18 introduced concurrent rendering, automatic batching and transitions.
- React 19 (Dec 2024): Actions, useActionState, useOptimistic, the use() hook, ref as a prop, and Server Components support.

? What is reconciliation? :: React compares the new element tree with the previous one and applies minimal DOM changes.
? Why keys in lists? :: Stable keys let React match items between renders and keep state correct.

@p7-3

@p7-5

@p7-6
Q: useMemo caches a computed value between renders until dependencies change; useCallback caches a function reference so memoised children (React.memo) don't re-render because of a new function prop. useCallback(fn, deps) equals useMemo(() => fn, deps).

@p7-7

@p7-18
Q: A closure is a function that remembers variables from the scope where it was created, even after that scope finished, for example a counter factory or a debounce function keeping its timer. React hooks rely heavily on closures.

```ts
function debounce<T extends (...a: any[]) => void>(fn: T, ms: number) {

}
```
